## Contexte

Projet d'école : une application web interactive pour consulter les derniers films sortis en salle.

## Ce que j'ai fait

- **API TMDB** : intégration de cette API externe de films.
- **Requêtes HTTP** : gestion des appels vers l'API.
- **Affichage dynamique** : une grille des films du moment, puis une fiche détaillée par film, à partir des données récupérées.
